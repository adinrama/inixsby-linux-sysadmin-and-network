## Setup Developer Team dengan Access Control
 
---
 
## **SCENARIO**
 
Lab server akan dipakai 3 developer untuk coding project. Mereka butuh:
- **User account masing-masing** (akun individual, bukan shared)
- **Shared project directory** dimana mereka bisa collaborate
- **Isolated home directory** (privacy antara developer)
- **Access control** (jangan bisa lihat file teman)
**Developer:** Rina, Budi, Citra
 
---
 
## **APA YANG PERLU DIBUAT**
 
1. **3 user account** (rina, budi, citra)
1. **1 group untuk team** (dev-team)
2. **Shared project directory** dengan proper permissions
3. **Access restrictions** (hanya team member bisa akses)
